Cortexia is a hospital management backend built with ASP.NET Core, MediatR, Entity Framework Core, SQL Server, ASP.NET Identity, JWT authentication, SignalR notifications, and an external AI/RAG integration.

The documentation is organized around how the system is built and how contributors should extend it safely.

## Project Shape

The backend solution is split into four main projects:

| Project | Responsibility |
| --- | --- |
| `Cortexa.Api` | HTTP controllers, middleware, Swagger, SignalR hubs, request pipeline |
| `Cortexa.Application` | Use cases, commands, queries, handlers, DTOs, validation, mapping |
| `Cortexa.Domain` | Entities, enums, value objects, domain exceptions, domain services |
| `Cortexa.Infrastructure` | EF Core, SQL Server, repositories, Identity, JWT, email, external AI clients |

Most requests follow this path:

```text
Client -> API Middleware -> Controller -> MediatR -> Handler -> Repository/UnitOfWork -> DbContext -> SQL Server
```
