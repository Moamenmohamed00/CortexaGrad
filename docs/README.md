# Cortexia Docs

This folder contains the Mintlify documentation site for Cortexia.

## Local Preview

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run the docs site from this folder:

```bash
mint dev
```

The local preview is available at `http://localhost:3000`.

## Documentation Structure

- `getting-started/` covers setup, configuration, and authentication.
- `architecture/` explains the backend structure and runtime flows.
- `domains/` documents the main hospital management modules.
- `api-reference/` contains API-level documentation and OpenAPI assets.
- `development-guide/` explains how to extend the backend consistently.
- `operations/` captures deployment, environment, and troubleshooting notes.
