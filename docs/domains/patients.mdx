The Patients module manages patient records and patient-specific views.

Main API area:

```text
api/Patients
```

Typical operations:

- Create a patient.
- Update patient details.
- Retrieve a patient by ID.
- Retrieve patient details.
- List all patients.
- Retrieve a patient's admissions.

Application features live under:

```text
Cortexa.Application/Features/Patients
```
