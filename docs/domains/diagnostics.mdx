Diagnostics covers lab orders, lab results, and imaging studies.

Main API area:

```text
api/Diagnostics
```

Typical operations:

- Create lab orders.
- Add lab results.
- Upload imaging.
- Retrieve lab orders by admission.
- Retrieve lab results by order.
- Retrieve imaging by admission.
