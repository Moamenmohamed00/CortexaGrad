---

Admissions connect patients to active hospital stays, beds, and clinical records.

Main API area:

```text
api/admission
```

Typical operations:

- Get active admissions.
- Get admissions for a patient.
- Create or admit a patient.
- Discharge an admission.
- Get admission details.

Clinical data endpoints are usually nested under an admission route.
